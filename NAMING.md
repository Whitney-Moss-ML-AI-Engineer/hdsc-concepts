On 2026-10-10 the 13 working concept names were replaced with one-word brand names chosen from the IT-services/MSP name list. Concept IDs, codes, and GitHub repo names (`hdsc-<id>`) are unchanged so existing links keep working.

| Previous working name | New name | Concept ID |
|---|---|---|

| The Blueprint | **Infostrata** | `blueprint` |
| On Your Side | **Opshield** | `onyourside` |

| The Fix | **Techtonic** | `thefix` |
| Frontier | **Nexora** | `frontier` |
| No Patience for Bureaucracy | **Opsline** | `nopatience` |
| Built By | **Stackcore** | `builtby` |

| Plainly Put | **Infrasync** | `plainlyput` |
| The Standard | **Cybertrust** | `standard` |
| The Enterprise Grid | **Techgrid** | `enterprisegrid` |

Selection basis: each name was matched to the concept's archetype, theme, and audience (for example, Techgrid for the Corporate Grid / Ruler concept; Cybertrust for the verifiable-standards concept; Nexora for the Explorer concept). No two names share a root. **None of these names has been trademark- or domain-cleared.** Run a USPTO/state search and domain check before public use.
