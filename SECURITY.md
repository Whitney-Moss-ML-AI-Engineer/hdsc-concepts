# Security Policy

Heavy Duty Security Co., LLC takes the security of its websites and software seriously.

## Reporting a vulnerability

Please report suspected vulnerabilities **privately**. Use the **Report a vulnerability** button on this repository's **Security** tab (GitHub private vulnerability reporting), or contact HDSC through the business contact details published on the project website and mark the message "Security". Please do not open a public issue for a security problem.

Include a description of the issue, steps to reproduce, and the potential impact. Please avoid accessing data that is not your own, degrading service, or testing against systems you do not own. We will acknowledge good-faith reports and work to resolve valid findings promptly.

## Scope

This repository contains a static website concept (HTML, CSS, and catalog data). It does not process payments or store credentials. Reports about HDSC's other web properties are also welcome.

## Our security approach

HDSC's security program is organized around the NIST Cybersecurity Framework and draws on NIST SP 800-53, NIST SP 800-171, CIS Critical Security Controls, and ISO/IEC 27001 as references, with Zero Trust principles guiding access decisions. See the project's Security & Trust page (`security-and-trust.html`) for a plain-language summary.

## Certification status

HDSC describes its practices as *aligned with* the frameworks above. It does **not** currently claim CMMC certification, FedRAMP authorization, or ISO/IEC 27001 certification. This policy is informational and is not a warranty.

## Contributor hygiene

- Never commit secrets, credentials, API keys, or personal data.
- Use multi-factor authentication on your GitHub account.
- Keep dependencies minimal and reviewed.
